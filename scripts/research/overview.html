Speed-driven adaptation

Turn runtime feedback into faster decoding.

In speculative decoding, optimizing for draft–target agreement alone can reduce throughput when a closer match comes at the expense of intrinsic draft speed. SPIRIT optimizes as it decodes, using window-level realized throughput to steer the search for a faster self-draft. Beyond a single request, SPIRIT adapts across workloads by recognizing familiar decoding patterns and reusing a saved draft configuration when a short probe confirms its speed advantage.

Optimize online

SPIRIT evaluates each self-draft by how quickly the full draft–verify cycle adds tokens to the answer. The same forward passes that produce those tokens also guide the next refinement.

Adapt to workloads

SPIRIT adapts as workloads shift, using early decoding feedback to decide whether to reuse a tuned draft, refine it for the new request, or search anew. Profile reuse raised mixed-stream throughput by 9.8–10.3% over the no-reuse baseline.

Preserve the target distribution

SPIRIT can skip sublayers and use NF4 weights to speed up drafting. The full target model verifies every proposal, so the output follows the same distribution as standard autoregressive decoding.
